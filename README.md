# Smart TV IA — versões publicadas

Este repositório público só guarda os APKs e o `version.json` que o app **Smart TV IA** consulta para se atualizar sozinho na TV.

- Última versão: aba **Releases** (arquivo `smart-tv-ia.apk`).
- Instalar pelo computador: `adb install -r smart-tv-ia.apk`
- O código-fonte fica em um repositório separado.
